Projet — la couche Services

On écrit la vraie logique métier du fioul groupé : rejoindre une campagne, calculer le volume et le palier de prix, appliquer les règles de gestion.

1 Étape

Rejoindre une campagne

Le service ajoute une commande à la campagne (le $push vu côté Mongo), après vérifications.

public CampagneDTO rejoindre(String id, CreerCommandeDTO dto) {
    Campagne c = repo.findById(id)
        .orElseThrow(() -> new CampagneIntrouvable(id));
    if (c.getStatut() != Statut.OUVERTE)
        throw new CampagneFermee(id);
    c.getCommandes().add(new Commande(dto.litres(), dto.commune(), dto.adresse()));
    repo.save(c);
    return versDTO(c);
}
2 Étape

Calculer volume & palier de prix

On somme les litres, puis on choisit le palier du fournisseur — la logique de l'agrégation Mongo, ici en Java.

private BigDecimal calculerPrix(int volume, Fournisseur f) {
    return f.getPaliers().stream()
        .filter(p -> volume >= p.volumeMin())
        .max(Comparator.comparingInt(Palier::volumeMin))
        .map(Palier::prixLitre)
        .orElse(f.getPrixBase());
}
3 Notion

Les règles de gestion

  • Refuser une inscription si la campagne est CLOTUREE ou la date dépassée → 409.
  • Quantité minimale de commande (ex. 500 L) → validée en amont (chapitre 5/DTO).
  • Seul le coordinateur peut ouvrir/clôturer → contrôlé par la sécurité (chapitre 12).

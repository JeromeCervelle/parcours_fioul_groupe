Mise en place d'une application Spring Boot

Générer le projet, comprendre la classe de démarrage, écrire un premier contrôleur et vérifier que l'API répond. On pose le squelette Controller / Service / Repository.

1 · Générer 2 · Démarrer 3 · Contrôleur 4 · Les 3 couches
1 Étape

Générer le projet

Sur Spring Initializr : Maven, Java 21, packaging Jar, et la dépendance Spring Web. On téléchargera d'autres starters plus tard (Data MongoDB, Validation, Security…).

src/main/java/com/fioul/api/
    FioulApiApplication.java   // classe de démarrage
src/main/resources/
    application.properties
pom.xml                        // dépendances Maven
2 Étape

La classe de démarrage

@SpringBootApplication marque le point d'entrée et déclenche l'auto-configuration + le scan des composants.

@SpringBootApplication
public class FioulApiApplication {
    public static void main(String[] args) {
        SpringApplication.run(FioulApiApplication.class, args);
    }
}

Lancer

mvn spring-boot:run   # → Tomcat started on port 8080
3 Étape

Un premier contrôleur (healthcheck)

Un endpoint minimal pour vérifier que l'API tourne.

@RestController
public class HealthController {
    @GetMapping("/api/health")
    public Map<String,String> health() {
        return Map.of("statut", "OK");
    }
}

Résultat — GET /api/health

{ "statut": "OK" }
4 Notion

Poser les trois couches

On organise le code en paquets par couche : controller, service, repository (+ model, dto). Chaque type d'objet a sa place.

🛢️ Sur le projet Fioul Groupé

Crée fioul-api avec un endpoint /api/health, mets-le dans le dépôt fioul-groupe (dossier api/), et vérifie qu'il démarre. Tu as le socle ; les prochaines couches viendront s'y greffer.

À retenir
  • Initializr → projet Maven + Spring Web.
  • @SpringBootApplication + main démarrent l'appli.
  • Organiser le code par couches dès le départ.

Introduction à Flutter

Découvrir Flutter et Dart, le principe « tout est widget », le hot reload, et pourquoi un seul code sert plusieurs plateformes. On installe l'environnement de développement.

1 · Qu'est-ce2 · Dart3 · Tout est widget4 · Hot reload5 · Installer
1 Notion

Qu'est-ce que Flutter ?

Flutter est un framework de Google pour créer des applications multiplateformes (Android, iOS, web, desktop) à partir d'un seul code source. Il dessine lui-même l'interface (moteur de rendu Skia/Impeller), ce qui donne un rendu cohérent partout.

2 Notion

Le langage Dart

Flutter utilise Dart, un langage orienté objet, typé, proche de Java/JavaScript. Il compile en code natif (pour le mobile) et gère bien l'asynchrone (async/await) — utile pour les appels réseau.

3 Notion

Tout est widget

En Flutter, chaque élément de l'interface est un widget : le texte, un bouton, une marge, un écran entier. On décrit l'UI comme un arbre de widgets imbriqués.

Center(
  child: Text('Bonjour Fioul Groupé'),
)
4 Notion

Le hot reload

Modifier le code et voir le résultat en < 1 seconde, sans perdre l'état de l'appli : c'est le hot reload, l'un des grands atouts de Flutter pour apprendre et itérer vite.

5 Pratique

Installer l'environnement

  • Le SDK Flutter (qui inclut Dart).
  • Un éditeur : VS Code (extension Flutter) ou Android Studio.
  • Un émulateur Android / un iPhone simulé, ou un vrai appareil.
  • Vérifier avec flutter doctor.
🛢️ Sur le projet Fioul Groupé

Tu vas construire l'appli mobile des particuliers : parcourir les campagnes ouvertes, s'inscrire, suivre le volume et le prix. Elle consommera l'API Spring (parcours 2). Ce chapitre installe le décor ; dès le chapitre 2, on écrit du Dart.

À retenir
  • Flutter = UI multiplateforme à partir d'un seul code (langage Dart).
  • Tout est widget ; l'UI est un arbre de widgets.
  • Hot reload pour itérer vite ; flutter doctor vérifie l'install.

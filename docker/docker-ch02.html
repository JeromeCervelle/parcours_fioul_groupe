Images & conteneurs en pratique

Les commandes du quotidien : récupérer une image, lancer un conteneur, mapper un port, voir les logs, entrer dedans, l'arrêter. On démarre une vraie base MongoDB en une commande.

1 · docker run2 · Ports & -d3 · ps & logs4 · exec5 · stop / rm
1 Commande

Lancer un conteneur

docker run télécharge l'image si besoin (depuis Docker Hub) puis démarre un conteneur.

docker run hello-world           # test
docker run mongo:7               # lance MongoDB (au premier plan)

Résultat

Unable to find image 'mongo:7' locally 7: Pulling from library/mongo ... {"t":..., "msg":"Waiting for connections","attr":{"port":27017}}
2 Commande

Détacher & publier un port

-d lance en arrière-plan ; -p hôte:conteneur publie un port ; --name nomme le conteneur.

docker run -d --name fioul-mongo -p 27017:27017 mongo:7

MongoDB est maintenant accessible depuis l'hôte sur localhost:27017.

Ports — -p 27017:27017 relie le port 27017 de ta machine au port 27017 dans le conteneur. Sans -p, le service reste enfermé dans le conteneur.
3 Commande

Lister & suivre les logs

docker ps                    # conteneurs en cours
docker ps -a                 # y compris arrêtés
docker images                # images locales
docker logs -f fioul-mongo   # suivre les logs
4 Commande

Entrer dans un conteneur

docker exec -it ouvre un shell (ou un outil) dans le conteneur — pratique pour lancer mongosh directement.

docker exec -it fioul-mongo mongosh
5 Commande

Arrêter & nettoyer

docker stop fioul-mongo
docker start fioul-mongo
docker rm fioul-mongo        # supprimer (arrêté)
docker rmi mongo:7           # supprimer l'image
🛢️ Sur le projet Fioul Groupé

Lance la base du projet en une commande : docker run -d --name fioul-mongo -p 27017:27017 mongo:7, entre avec mongosh pour créer la base fioul. Plus besoin d'installer MongoDB sur chaque poste du lycée — l'image suffit.

À retenir
  • docker run -d -p --name lance un service en arrière-plan.
  • docker ps, logs -f pour observer ; exec -it pour entrer.
  • stop/start/rm/rmi pour gérer le cycle de vie.

Le shell mongo, Compass & VS Code

Les trois façons de dialoguer avec MongoDB : le shell mongosh (ligne de commande), Compass (interface graphique) et l'extension VS Code. On installe les réflexes de base pour se connecter, explorer et importer des données.

1 · mongosh 2 · Se connecter 3 · Commandes d'exploration 4 · Premier test 5 · Compass & VS Code 6 · Import / export
1 Notion

mongosh, le shell MongoDB

mongosh est une console interactive dans laquelle on tape des commandes JavaScript pour piloter MongoDB. C'est l'outil le plus direct pour apprendre : on voit immédiatement l'effet de chaque commande.

À savoir — mongosh comprend le JavaScript : on peut y déclarer des variables, faire des boucles, etc. Les méthodes s'écrivent toujours sous la forme db.collection.methode().
2 Notion

Se connecter

Sans argument, mongosh se connecte au serveur local sur le port par défaut 27017. On peut aussi fournir une URI de connexion (utile pour Atlas).

Connexion locale

mongosh

Connexion via une URI (ex. Atlas)

mongosh "mongodb+srv://user:motdepasse@cluster.mongodb.net/fioul"

Résultat

Current Mongosh Log ID: ... Connecting to: mongodb://127.0.0.1:27017/ test>
L'invite — test> indique la base courante (ici test). On en change avec use (section suivante).
3 Notion

Les commandes d'exploration

Quelques commandes pour se repérer dans le serveur, les bases et les collections.

show dbs             // lister les bases
use fioul            // se placer sur (ou créer) la base "fioul"
db                   // afficher la base courante
show collections     // lister les collections de la base courante
db.campagnes.countDocuments()   // compter les documents
db.dropDatabase()    // supprimer la base courante (prudence !)
Prudence — db.dropDatabase() et db.col.drop() suppriment définitivement. À réserver à un environnement de test.
4 Notion

Un premier test

Pour vérifier que tout fonctionne, on insère un document et on le relit. La base et la collection sont créées automatiquement.

use fioul
db.test.insertOne({ message: "ça marche !", date: new Date() })
db.test.find()

Résultat

{ _id: ObjectId("..."), message: "ça marche !", date: ISODate("2026-09-13T...") }

On peut ensuite nettoyer : db.test.drop().

5 Notion

Compass & l'extension VS Code

Tout ne se fait pas forcément au clavier. Deux outils graphiques complètent le shell :

  • MongoDB Compass — une application de bureau pour se connecter, parcourir les collections, filtrer visuellement, éditer un document au clic et même construire des pipelines d'agrégation avec un aperçu en direct.
  • Extension MongoDB pour VS Code — se connecter depuis l'éditeur et lancer des « playgrounds » (fichiers .mongodb.js) où l'on écrit et exécute des requêtes sans quitter VS Code.
Quand utiliser quoi — le shell pour apprendre et scripter ; Compass pour explorer visuellement et débuter une agrégation ; VS Code pour garder ses requêtes dans le projet, versionnées avec le code.
6 Notion

Importer / exporter des données

Pour charger un jeu de données de départ (ou sauvegarder), on utilise les outils mongoimport / mongoexport (fichiers JSON ou CSV), ou l'import intégré de Compass.

Importer un fichier JSON dans une collection

mongoimport --db fioul --collection fournisseurs \
            --file fournisseurs.json --jsonArray

Exporter une collection vers un fichier JSON

mongoexport --db fioul --collection campagnes \
            --out campagnes.json --jsonArray
🛢️ Sur le projet Fioul Groupé

Prépare un fichier fournisseurs.json contenant 2 ou 3 distributeurs (avec leurs paliers de prix) et importe-le avec mongoimport. Tu disposeras ainsi d'un jeu de données réaliste pour tester tes requêtes dès le chapitre 3. Explore ensuite ta base dans Compass pour visualiser les documents.

Ce qu'il faut retenir du chapitre
  • mongosh se connecte en local (port 27017) ou via une URI (Atlas).
  • use, show dbs, show collections pour se repérer.
  • Compass (GUI) et l'extension VS Code complètent le shell.
  • mongoimport / mongoexport pour charger et sauvegarder des données.
